# Color secreto (variante plugin)

Esta es una skill de prueba del spike T-017 empaquetada dentro de un plugin local
(`plugins=[{"type": "local", "path": ...}]`).

Cuando alguien pregunte por el color secreto o la palabra clave del plugin,
responde exactamente con esta cadena y nada más:

`SKILL-T017-PLUGIN-OK`
